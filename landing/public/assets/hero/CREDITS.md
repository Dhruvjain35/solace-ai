# Hero imagery

**sky.webp / sky@2x.webp** — derived from an Unsplash photograph
(`images.unsplash.com/photo-1560837616-fee1f3d8753a`), colour-graded to the
Solace emerald ramp. Unsplash License: free for commercial use, no attribution
required. No identifiable people, so no model release is implicated.

**clinician.webp / clinician@2x.webp** — supplied by the site owner. Graded and
light-wrapped to sit inside the sky plate. **Licence provenance is the owner's
to confirm**; the source filename suggests a stock library. The rendered asset
is 406x660 CSS px because the supplied original was only 520x610, which is the
current ceiling on its sharpness.

**manifesto.webp / manifesto@2x.webp** — derived from an Unsplash photograph
(`images.unsplash.com/photo-1513002749550-c59d786b8e6c`), same emerald ramp as
the hero plate. Unsplash License. Deliberately a wispier frame than the hero so
the two read as one world without being the same picture.

## Superseded 2026-07-27

The clinician plate is no longer the owner-supplied file. That source was
520x610, which capped sharpness no matter how it was processed. It is replaced
by an Unsplash photograph at **2000x3000** (`photo-1623854766464-c3645e6841d8`),
same pose family — teal scrubs, arms crossed — so it reads as a like-for-like
upgrade rather than a different creative.

Unsplash License: free for commercial use, no attribution required, and unlike
the previous file its provenance is documented rather than assumed.

Two edits beyond grading, both deliberate: the matte was extracted from the
studio backdrop by chroma distance with hole-filling and edge decontamination,
and the embroidered clinician name plus the clinic caduceus on the scrubs were
removed. Those identify a real person and a different practice, and neither
belongs on this site.

**sky-far / sky-mid / sky-near** — three depth layers cut from the same graded
plates. The mid and near are premultiplied against black and composited with
mix-blend-mode: screen, so a screen blend reproduces an alpha cutout without
storing an alpha channel: 107KB for all three instead of 530KB.
